# Support

For CLI usage or GitHub-adapter questions, open a [ContribReady CLI issue](https://github.com/ContribReady/contribready-cli/issues/new) and include the CLI version, operating system, command with secrets removed, input kind (local or GitHub), and sanitized output. GitHub Discussions are not enabled for this repository.

Do not include `GITHUB_TOKEN` or private repository content. Security reports must be sent privately according to `SECURITY.md`.
